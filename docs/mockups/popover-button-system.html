Until — ボタン可視性システム

「状態は常時見える・可能性はホバーで現れる・移動系は展開に住む・設定系は右クリックに住む」の4層ルールに全面統一する提案。右のモックは実際にホバーで動きます。

4層ルール

層ルール該当アクション
1 · 主役 1画面に1つだけの目立つボタン。ヒーローカードとストリップのみ Join(ヒーロー/ストリップ)
2 · 状態 イベントが「持っているもの」は常時グリフ表示=クリック可。未来の行だけ 📹 通話あり → Join / 📄 ノートあり → Open notes
3 · 可能性 「作れるもの」はホバーで現れる Create notes / Add Meet / (ヒーローの)Open in Calendar
4 · 低頻度 移動・複製系は展開ビュー、設定系は右クリックのみ Open in Calendar / Copy details / Copy link / Skip in menubar

現状からの変更点

  • ヒーローのrest状態は Join + Notes の2つだけに。「Open in Calendar」は常駐をやめ、ホバーで3つ目として現れる(展開・右クリックにもある)
  • ヒーローの Create notes もrest表示に昇格。ノート未作成でも会議前の主要アクションなので、ホバー待ちにしない(ノート有無でラベルが変わるだけ)
  • 過去行はアクション全撤去。ノートがある場合の📄だけ残す(振り返り導線)。Joinは意味がないので右クリックからも消す
  • 未来行は現状維持を明文化: 📹/📄は状態グリフとして常時、Create notes / Add Meet はホバー
  • 展開ビューの Open in Calendar / Copy details は現状のまま(第4層の正式な住所になる)
  • ストリップは Join のみ(現状のまま)

💡 迷ったときの判定: それはイベントの属性か(→常時)、これから作るものか(→ホバー)、別の場所に行くのか(→展開)、設定を変えるのか(→右クリック)。
