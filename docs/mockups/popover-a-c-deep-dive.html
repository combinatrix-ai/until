Until — A / C 深掘り

A案は「ヒーローもタイムラインの一部」という前提で2方向。C案はビッグカウントダウンが NOW / NEXT どちらなのかを一目で区別できるかを、2状態並べて検証。

A — ヒーローとタイムラインの関係

A-1はヘッダーを廃止してヒーローをタイムライン内に埋め込む。開いた瞬間のスクロール位置が「今」で、過去は上にスクロールすると出てくる。A-2は現行のピン留めヘッダーを残しつつ、同じイベントをタイムライン側にも残して線を切らない。

A-1埋め込みヒーロー(開いたら「今」が先頭)

ヘッダーという別世界をなくし、NOWカードがレールの上に直接乗る。NEXTはすぐ下の強調行なので、Now / Next が同じ視線移動の中にある。

  • 効き所: タイムラインが1本で完結。過去↔今↔未来が同じ座標系
  • 効き所: NOWとNEXTが常に隣接して見える(会議中に「次どこ行くんだっけ」が速い)
  • 論点: スクロールで NOW カードが画面外に消える。ピン留め(スクロール時だけ縮小ヘッダー化)を足すか?

A-2ピン留めヘッダー+タイムラインに残す

現行のヘッダーは維持(常時見える・アクションが一等地)。ただし同じイベントがタイムラインからも消えず、NOWチップ付きの強調行として線の上に残る。

  • 効き所: Join/Notesが常に画面上部の同じ場所(筋肉記憶が効く)
  • 効き所: タイムラインは全イベントを含む完全な1日になる
  • 論点: 同じ情報が2回出る冗長さをどこまで許すか(行側は薄めに寄せる手も)

C — ビッグカウントダウンの NOW / NEXT 判別

数字だけでは「次まで7分」なのか「残り7分」なのか判別できないので、(1)キッカー行のラベル+終端時刻 (2)数字の色(青=NEXT, 緑=NOW) (3)NOWのみ進捗バー、の3点で状態を刻む。左が NEXT、右が NOW。

CNEXT状態 — 「in 7 min」

  • ラベルは UP NEXT · 2:00 PM(開始時刻を添える)
  • 数字はアクセント色(青)+接頭辞「in」で「まだ始まってない」を示す
  • 進捗バーなし=未開始、の消極的シグナルも兼ねる
